# 경력직 처우검토 및 오퍼레터 관리시스템 v3.2

## 주요 기능

- 후보자 여러 명 등록·검색·재조회
- SQLite DB 영구 저장 및 기존 DB 자동 마이그레이션
- 건강보험 자격득실확인서 PDF/이미지 업로드 및 OCR
- 생년월일 6자리 암호화 PDF 분석 지원
- OCR 경력 후보 자동 생성
- OpenDART 회사 매칭 및 직전년도 연결매출 자동조회
- 관리자 화면에서 매출 구간별 경력 인정률 직접 설정
- DART 미확인 회사의 Google/Naver 검색 바로가기
- 외부자료의 매출연도·연결매출·출처 URL·증빙파일 수동확정
- 외부자료 확정 시 관리자 매출기준으로 인정률 자동계산
- 확인되지 않은 경력은 `확인필요`로 두고 확정 인정경력에서 제외
- 현재 보상과 제안 보상 비교
- 입사신분별 복리후생 검토
- 오퍼레터 DOCX 생성·다운로드·버전관리
- 저장 스냅샷 및 작업이력

## 실행 방법

최초 한 번:

```text
01_install.bat
```

이후 실행:

```text
02_run_app.bat
```

VS Code 터미널에서는:

```cmd
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 기존 데이터 유지

기존 프로젝트를 이미 사용하고 있다면 기존 프로젝트의 `data` 폴더를 새 프로젝트 폴더로 그대로 복사하세요.

```text
data/
├─ offer_system.db
├─ uploads/
└─ offers/
```

기존 DB는 최초 실행 시 필요한 새 열이 자동 추가됩니다. 기존 후보자 기록을 유지하려면 `data` 폴더를 삭제하지 마세요.

## DART 설정

1. 사이드바 `관리자 설정` → `DART 연동`
2. DART API 인증키 입력 → `API 키 저장`
3. `DART 기업목록 새로고침`
4. `매출 인정기준`에서 회사 기준의 매출 하한·상한·인정률 저장
5. 후보자 `③ 인정경력`에서 `DART 연결매출 조회·인정률 일괄반영`

회사 매칭, 직전년도 연결매출, 매출 기준구간 중 하나라도 확인되지 않으면 `확인필요`로 남습니다.

## DART에 없는 회사의 외부자료 확정

후보자 `③ 인정경력` 하단의 `DART 미확인 회사 · 외부자료 확정` 영역을 사용합니다.

1. 확인할 경력회사를 선택합니다.
2. `Google 검색` 또는 `Naver 검색` 버튼으로 회사명 + 기준연도 + 연결 매출액을 검색합니다.
3. 외부자료 출처를 선택합니다.
4. 매출 기준연도를 입력합니다.
5. 재무기준을 `연결`로 선택합니다.
6. 연결매출을 억원 단위로 입력합니다.
7. 근거 URL 또는 증빙파일을 첨부합니다.
8. `외부자료 매출 확정 · 인정률 자동적용`을 누릅니다.

확정 시 관리자가 설정한 매출구간에 따라 인정률이 자동 계산됩니다. 재무기준이 `별도` 또는 `구분확인필요`인 자료는 연결매출 기준으로 자동확정하지 않습니다.

외부자료 확정값은 다음 정보와 함께 DB에 저장됩니다.

- 외부자료 출처
- 근거 URL
- 매출 기준연도
- 연결매출액
- 재무기준
- 증빙파일 경로
- 적용 인정률
- 확인 메모

## 암호화 PDF

건강보험 자격득실확인서가 생년월일 6자리로 암호화되어 있으면 `증빙문서·OCR` 탭의 `PDF 비밀번호 — 생년월일 6자리`에 입력합니다. 비밀번호는 DB, 변경이력, 스냅샷, 파일명에 저장하지 않습니다.

## OCR

문자형 PDF는 Tesseract 없이도 직접 문자추출이 가능합니다. 스캔 PDF/이미지는 Windows에 Tesseract와 한국어 언어데이터가 별도로 설치되어 있어야 합니다.

프로그램은 다음 순서로 Tesseract를 찾습니다.

1. 환경변수 `TESSERACT_CMD`
2. 시스템 PATH의 `tesseract`
3. `C:\Program Files\Tesseract-OCR\tesseract.exe`
4. `C:\Program Files (x86)\Tesseract-OCR\tesseract.exe`

## v3.5 보상비교 / Pay Band
관리자 설정 > Pay Band 기준에서 `pay_band_template.csv` 형식으로 CSV를 업로드하거나 표에 Excel 범위를 붙여넣고 저장합니다.
후보자 검토 > 보상비교에서 직급(G1~G4/R1~R4), G4/R4의 일반/팀장/실장 구분, BAND를 선택하면 저장된 기준 금액이 당사 제안 항목에 자동 반영됩니다.
계약연봉은 기본급+업적급+고정연장수당으로 계산하며, 총연봉은 계약연봉+성과급+현금성지급 복리후생 9종으로 계산합니다.

## v3.6 원 단위 / 입사신분별 복리후생

### 금액 단위
- 보상비교와 Pay Band의 모든 금액은 `원` 단위입니다.
- 화면에서는 `50,000,000`처럼 천단위 쉼표로 표시합니다.
- v3.5 이하 DB의 보상/Pay Band 금액은 최초 실행 시 만원 → 원으로 1회 자동 변환됩니다.

### 복리후생 기준
관리자 설정 > `복리후생 기준`에서 다음 5가지 조건 조합별 기준을 저장합니다.

- 직군: 일반직 / 연구직 / 별정직 / 기술직
- 계약구분: 정규직 / 계약직 / 파견직
- 근무지: 인천 / 당진 / 포항 / 순천 / 판교
- 입사구분: 신입입사 / 경력입사
- 직급: G1 / G2 / G3 / G4 / R1 / R2 / R3 / R4

`복리후생 항목 마스터 및 설명 편집`에서 항목명·분류·설명을 수정하거나 새로운 항목을 추가할 수 있습니다.
조건을 선택한 뒤 체크박스로 적용항목을 선택하고 `현재 조건 복리후생 저장`을 누릅니다.

후보자 검토 > `⑤ 복리후생`에서는 현재 후보자의 5가지 조건에 맞는 관리자 기준을 불러옵니다.
불러온 뒤에도 행 추가·삭제, 적용/조건부/미적용 변경, 설명 수정, 오퍼레터 포함 여부 변경이 가능합니다.

현금성 보상에서 별도 관리하는 귀향여비, 선택형 복지포인트, 자기계발지원금, 체력단련비, 개인연금은 기본 복리후생 체크목록에서 제외했습니다.
